How it is measured

The protocol is agreed
before the work starts.

AI answers vary by session, location and login state. So the method is fixed in writing on day one and every run is evidenced.

01

What counts as a citation

Your brand name in the answer body, or your domain in the source panel. A third-party page that mentions you but does not name or link you is not counted.

02

Clean-room conditions

Logged out, fresh session, personalization and memory off, fixed locale declared on day one, default consumer model per engine, query pasted verbatim with no follow-ups.

03

Three runs, majority rule

Each query, on each engine, three times. Two of three counts as cited. One of three is logged as partial. This is how we handle the variability rather than argue about it later.

04

Evidence for every run

Timestamped screenshot plus raw answer text, saved to your shared folder. Nothing appears in a report that is not in the folder.

05

When an engine does not answer

If an engine returns no AI answer for a query, it is excluded from that query's result rather than recorded as a miss. Written into the agreement, not decided later.

06

You can verify it yourself

Re-run any query under the same documented protocol. Disagreements are settled by a joint re-run within five business days of the day-90 report.
